Microsoft Azure Synapse & Power BI Reports

Microsoft Azure Severless Pool SQL Power BI

1. Problem & Challenge

Multi-Company Data Consolidation & Stakeholder Reporting

The client approached us with massive volumes of historical and ongoing operational data spanning multiple portfolio companies. The dataset contained complex cross-channel metrics including marketing performance, overall sales, business growth, and ROI.

Each individual company—as well as various specialized internal teams (Sales, Organic Social, Paid Social, Email Marketing, Website Ops, and Executive Business teams)—required distinct, localized views of performance data. The core challenge was centralizing this vast multi-company dataset without exposing confidential cross-brand metrics or departmental figures to unauthorized teams.

2. Solution & Work Done

The Fix: Serverless Abstraction Layer

Instead of building rigid ETL jobs or provisioning costly SQL databases, I engineered an abstraction virtualization layer using Azure Synapse Serverless SQL.

    * Configured `EXTERNAL DATA SOURCE` and `EXTERNAL FILE FORMAT` objects directly over ADLS Gen2. * Used `OPENROWSET` with `WITH` schema clauses to query all raw Parquet partitions on-the-fly. * Applied explicit `CAST` and `ISNULL()` handling inside T-SQL views to normalize column count variations across historical partitions. * Connected Power BI to the dynamic T-SQL view, establishing a clean Star Schema and automated DAX calculations without pipeline crashes.

4. Schema Drift Implementation (T-SQL)

Here is the core view abstraction created inside Azure Synapse Serverless SQL to handle variable column counts across raw Parquet files:

CREATE VIEW vw_marketing_analytics AS
SELECT 
    CAST(CampaignID AS VARCHAR(50))                      AS campaign_id,
    CAST(Impressions AS INT)                             AS impressions,
    CAST(Clicks AS INT)                                  AS clicks,
    -- Normalizes missing columns in 5-column files vs 7-column files:
    ISNULL(CAST(AdGroup AS VARCHAR(50)), 'Unassigned')   AS ad_group,
    ISNULL(CAST(Region AS VARCHAR(50)), 'Global')        AS region
FROM OPENROWSET(
    BULK 'marketing/*/*/*.parquet',
    DATA_SOURCE = 'AzureDataLakeStore',
    FORMAT = 'PARQUET'
) WITH (
    CampaignID VARCHAR(50),
    Impressions INT,
    Clicks INT,
    AdGroup VARCHAR(50),
    Region VARCHAR(50)
) AS [result];
